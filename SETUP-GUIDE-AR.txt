═══════════════════════════════════════════════════════════════════
                      خطوات التثبيت
═══════════════════════════════════════════════════════════════════

1️⃣ استخراج الملفات:
   - استخرج ملف website-export.zip أو website-export.tar.gz
   - انسخ جميع الملفات إلى المجلد:
     C:\Users\pc\Desktop\web\

2️⃣ الهيكل المطلوب:
   C:\Users\pc\Desktop\web\
   ├── index.html
   ├── styles/
   │   └── main.css
   ├── js/
   │   ├── main.js
   │   └── booking.js
   └── README.md

3️⃣ تشغيل الموقع:

   الطريقة 1: فتح مباشر
   ━━━━━━━━━━━━━━━━━━━
   - افتح ملف index.html مباشرة بالمتصفح (Windows Explorer)
   - انقر نقراً مزدوجاً على الملف

   الطريقة 2: استخدام Local Server (موصى به)
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   أ) باستخدام Python (إذا كان مثبت):
      - افتح Command Prompt
      - انتقل للمجلد:
        cd C:\Users\pc\Desktop\web
      - شغل الخادم:
        python -m http.server 8000
      - افتح المتصفح واكتب:
        http://localhost:8000

   ب) باستخدام Node.js (إذا كان مثبت):
      - افتح Command Prompt
      - انتقل للمجلد:
        cd C:\Users\pc\Desktop\web
      - شغل الخادم:
        npx http-server
      - افتح رابط الموقع المعروض

   ج) باستخدام Live Server في VS Code:
      - افتح المجلد في VS Code
      - اضغط Alt+L ثم Alt+O
      - الموقع سيفتح تلقائياً

❗ الحفاظ على البنية:
   - تأكد من أن المجلدات styles/ و js/ موجودة
   - لا تحرك أو تعيد تسمية الملفات

🔗 الروابط:
   - تأكد من أن جميع الروابط في index.html صحيحة
   - يجب أن تشير إلى styles/main.css و js/*.js

📱 الاختبار:
   - اختبر على أجهزة مختلفة (موبايل، تابلت، ديسكتوب)
   - استخدم F12 لفتح DevTools والتحقق من الأخطاء

🌐 المتصفحات:

   - Chrome, Firefox, Safari, Edge
