            Icon Monde Professional Website Setup Guide

This guide will help you install the website on your personal computer.

═══════════════════════════════════════════════════════════════════
                      Installation Steps
═══════════════════════════════════════════════════════════════════

1️⃣ Extract Files:
   - Extract website-export.zip or website-export.tar.gz
   - Copy all files to:
     C:\Users\pc\Desktop\web\

2️⃣ Required Structure:
   C:\Users\pc\Desktop\web\
   ├── index.html
   ├── styles/
   │   └── main.css
   ├── js/
   │   ├── main.js
   │   └── booking.js
   └── README.md

3️⃣ Running the Website:

   Method 1: Direct Open
   ━━━━━━━━━━━━━━━━━━━
   - Open index.html directly in your browser (Windows Explorer)
   - Double-click the file

   Method 2: Local Server (Recommended)
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   a) Using Python (if installed):
      - Open Command Prompt
      - Navigate to folder:
        cd C:\Users\pc\Desktop\web
      - Run server:
        python -m http.server 8000
      - Open browser and type:
        http://localhost:8000

   b) Using Node.js (if installed):
      - Open Command Prompt
      - Navigate to folder:
        cd C:\Users\pc\Desktop\web
      - Run server:
        npx http-server
      - Open the displayed URL

   c) Using Live Server in VS Code:
      - Open folder in VS Code
      - Press Alt+L then Alt+O
      - Website opens automatically

❗ Maintain Structure:

═══════════════════════════════════════════════════════════════════
                      Troubleshooting
═══════════════════════════════════════════════════════════════════

❌ Website doesn't work:
   ✓ Verify all files exist
   ✓ Check folder names (case-sensitive on Linux/Mac)
   ✓ Use Local Server instead of direct file open

❌ No styling or animations:
   ✓ Open DevTools (F12)
   ✓ Verify CSS and JS are loaded
   ✓ Check Console for errors

❌ Form doesn't work:
   ✓ Ensure js/booking.js is loaded
   ✓ Check Console for errors
   ✓ Refresh page (F5)
